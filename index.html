Классификация OSINT-инструментов и команды запуска

Поисковые системы и метапоиск

  • Whatsmyname.me — поиск имени пользователя (username) на 500+ онлайн-платформах для оценки цифрового следа. whatsmyname.me
  • Telegago (Google CSE) — кастомный поисковик от Bellingcat для нахождения публичных каналов и групп Telegram через Google. cse.google.com
  • ZoomEye — сканер киберпространства: находит открытые интернет-устройства (роутеры, серверы, веб-камеры) и оценивает поверхность атаки. zoomeye.ai
  • Boardreader — индексирует обсуждения на форумах, досках объявлений и в дискуссионных сообществах. boardreader.com
  • Ahmia.fi — поисковик по .onion-сайтам в сети Tor. ahmia.fi

Изображения и видео

  • TinEye — обратный поиск изображений: находит первоисточник, изменённые версии и копии в высоком разрешении. tineye.com
  • PimEyes — поиск лиц по фотографии среди публично доступных изображений в интернете. pimeyes.com
  • BetaFace (Demo) — демонстрационный сервис распознавания лиц: ключевые точки, сравнение, анализ. betaface.com
  • Shadowmap — 3D-модель положения солнца и теней в заданной точке и времени, помогает геолоцировать фото и видео. app.shadowmap.org
  • GeoHints — справочник визуальных маркеров стран: дорожные знаки, номерные знаки, столбы, почтовые ящики. geohints.com
  • Pl@ntNet — идентификация растений по фотографии, полезно при анализе окружающей среды на снимках. identify.plantnet.org

Утечки данных и безопасность

  • h8mail — поиск утечек и паролей по email-адресу через HaveIBeenPwned, Dehashed и локальные базы. GitHub
    Установка через pip: 
    pip3 install h8mail
    Одноразовый запуск в Docker (справка): 
    docker run -ti --rm kh4st3x00/h8mail -h
  • Betterleaks — быстрый сканер секретов (API-ключей, паролей, токенов) в git-репозиториях с live-валидацией найденного. GitHub
    Установка через Homebrew: 
    brew install betterleaks
    Установка через Go: 
    go install github.com/betterleaks/betterleaks/v2@latest
    Одноразовый запуск в Docker (сканирование текущей папки): 
    docker run --rm -v "$(pwd):/src" ghcr.io/betterleaks/betterleaks:latest /src
  • Gitleaks — SAST-сканер жёстко закодированных секретов в git-истории и файлах; работает как CLI, pre-commit hook или GitHub Action. GitHub
    Одноразовый запуск в Docker (сканирование локального репозитория): 
    docker run --rm -v "$(pwd):/repo" ghcr.io/gitleaks/gitleaks:latest git /repo
    Альтернативный образ на Docker Hub: 
    docker run --rm -v "$(pwd):/path" zricethezav/gitleaks:latest detect --source="/path" -v

Анализ сетей и инфраструктуры

  • Iknowwhatyoudownload.com — показывает, какие торренты скачивались и раздавались с конкретного IP-адреса по данным DHT. iknowwhatyoudownload.com
  • Fluxion — аудит Wi-Fi: поднимает фейковую точку доступа и через социальную инженерию выманивает пароль WPA/WPA2. GitHub
    Клонирование репозитория: 
    git clone https://github.com/FluxionNetwork/fluxion.git
cd fluxion
    Запуск (нужны права root и зависимости): 
    sudo ./fluxion
  • Kolyma.ru WhoIs — WHOIS-информация о домене: владелец, контакты, nameservers. kolyma.ru/who

Telegram-боты

  • @MotherSearchBot — поиск по каналам, сообщениям, аудио и документам внутри Telegram. @MotherSearchBot
  • @eyeofbeholder_bot — строит профиль интересов пользователя по его подпискам на каналы и чаты. @eyeofbeholder_bot

Username, email, домены

  • NameVine — быстрая проверка занятости username и домена в топ-10 соцсетях (Twitter, GitHub, Instagram и др.). namevine.com
  • Snoop — поиск по никнейму на тысячах сайтов с усиленным покрытием русскоязычного сегмента (СНГ). GitHub Releases
    Установка из исходников: 
    git clone https://github.com/snooppr/snoop.git
cd snoop
pip3 install -r requirements.txt
    Запуск: 
    python3 snoop.py
    Готовые бинарные сборки без Python доступны на странице Releases.
  • Sherlock — поиск аккаунтов по имени пользователя на 400+ социальных сетях и сайтах. GitHub
    Установка через pipx (рекомендуется): 
    pipx install sherlock-project
    Одноразовый запуск в Docker: 
    docker run --rm -t sherlock/sherlock USERNAME
    Замените USERNAME на искомый никнейм.
  • EyeOfGod — платформа поиска и анализа информации: поиск по изображениям и проверка источников. eyeofgod.app
