Утечки данных и безопасность

  • h8mail — OSINT-инструмент для поиска утечек по email. GitHub
    Установка через pip: 
    pip3 install h8mail
    Одноразовый запуск в Docker (справка): 
    docker run -ti --rm kh4st3x00/h8mail -h
  • Betterleaks — быстрый сканер секретов в git-репозиториях. GitHub
    Установка через Homebrew (macOS/Linux): 
    brew install betterleaks
    Установка через Go: 
    go install github.com/betterleaks/betterleaks/v2@latest
    Одноразовый запуск в Docker (сканирование текущей папки): 
    docker run --rm -v "$(pwd):/src" ghcr.io/betterleaks/betterleaks:latest /src
  • Gitleaks — SAST-инструмент для поиска секретов в git-репозиториях. GitHub
    Одноразовый запуск в Docker (сканирование локального репозитория): 
    docker run --rm -v "$(pwd):/repo" ghcr.io/gitleaks/gitleaks:latest git /repo
    Или через Docker Hub: 
    docker run --rm -v "$(pwd):/path" zricethezav/gitleaks:latest detect --source="/path" -v

Анализ сетей и инфраструктуры

  • Iknowwhatyoudownload.com — веб-сервис, команды не требуются. iknowwhatyoudownload.com
  • Fluxion — аудит Wi-Fi сетей. GitHub
    Скачивание и переход в папку: 
    git clone https://github.com/FluxionNetwork/fluxion.git
cd fluxion
    Запуск (потребуются права root и зависимости): 
    sudo ./fluxion
  • Kolyma.ru WhoIs — веб-страница, команды не требуются. kolyma.ru/who

Username, email, домены

  • NameVine — веб-сервис. namevine.com
  • Snoop — OSINT-поиск по никнейму (фокус на СНГ). GitHub Releases
    Установка из исходников (Linux/macOS): 
    git clone https://github.com/snooppr/snoop.git
cd snoop
pip3 install -r requirements.txt
    Запуск: 
    python3 snoop.py
    Готовые бинарные сборки также доступны на странице Releases (не требуют Python).
  • Sherlock — поиск аккаунтов по username на 400+ платформах. GitHub
    Установка через pipx (рекомендуется): 
    pipx install sherlock-project
    Одноразовый запуск в Docker: 
    docker run --rm -t sherlock/sherlock USERNAME
    Замените USERNAME на искомый никнейм. Для сохранения результата добавьте монтирование тома (см. документацию).
  • EyeOfGod — онлайн-сервис (веб-платформа), локальная установка не требуется. eyeofgod.app
