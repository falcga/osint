Классификация OSINT-инструментов

Поисковые системы и метапоиск

  • Whatsmyname.me — Поиск имени пользователя (username) на 500+ платформах для анализа цифрового следа. whatsmyname.me
  • Telegago (Google CSE) — Поисковая система от Bellingcat для поиска публичных каналов и групп в Telegram через Google. cse.google.com
  • ZoomEye — Поисковая система для киберпространства, сканирующая интернет-устройства (роутеры, серверы, веб-камеры) по всему миру. zoomeye.ai
  • Boardreader — Специализированная поисковая система по онлайн-форумам и дискуссионным площадкам. boardreader.com
  • Ahmia.fi — Поисковая система для контента в сети Tor (.onion-сайты). ahmia.fi

Инструменты для работы с изображениями и видео

  • TinEye — Оригинальный обратный поиск изображений. Помогает найти источник, изменённые версии и копии в высоком разрешении. tineye.com
  • PimEyes — Поиск лиц по фотографии на публично доступных веб-сайтах. pimeyes.com
  • BetaFace (Demo) — Демонстрационный инструмент для распознавания и анализа лиц на изображениях. betaface.com
  • Shadowmap — 3D-симуляция солнечного света и теней. Используется для геолокации по времени и месту съёмки. app.shadowmap.org
  • GeoHints — Справочник визуальных подсказок (дорожные знаки, номерные знаки и т.д.) для геолокации по фото. geohints.com
  • Pl@ntNet — Бесплатная идентификация растений по фотографии. identify.plantnet.org

Утечки данных и безопасность

  • h8mail — OSINT-инструмент для поиска утечек и паролей по email-адресу. Доступен как Docker-образ. github.com/kh4st3x00/h8mail
    Команда запуска: 
    docker run -ti kh4st3x00/h8mail -h
  • Betterleaks — Быстрый сканер секретов (паролей, API-ключей) в git-репозиториях и файловых системах. github.com/betterleaks/betterleaks
  • Gitleaks — SAST-инструмент для обнаружения жёстко закодированных секретов в git-репозиториях. github.com/gitleaks/gitleaks

Анализ сетей и инфраструктуры

  • Iknowwhatyoudownload.com — Сервис, показывающий, какие торренты скачивались с конкретного IP-адреса. iknowwhatyoudownload.com
  • Fluxion — Инструмент для аудита безопасности Wi-Fi сетей с использованием социальной инженерии. github.com/FluxionNetwork/fluxion
  • Kolyma.ru WhoIs — Страница для получения WHOIS-информации о домене (владелец, контакты, nameservers). kolyma.ru/who

Инструменты для Telegram

  • @MotherSearchBot — Мощная поисковая система внутри Telegram для поиска каналов, сообщений, аудио и документов. @MotherSearchBot
  • @eyeofbeholder_bot — Telegram-бот, анализирующий интересы пользователя на основе его подписок на каналы и чаты. @eyeofbeholder_bot

Инструменты для работы с username, email и доменами

  • NameVine — Быстрая проверка доступности имени пользователя и домена в популярных социальных сетях. namevine.com
  • Snoop — OSINT-инструмент для поиска по никнейму на тысячах сайтов, с фокусом на СНГ. github.com/snooppr/snoop
  • Sherlock — Поиск аккаунтов по имени пользователя (username) на 400+ социальных сетях. github.com/sherlock-project/sherlock
    Команда запуска: 
    docker run -it --rm sherlock/sherlock
  • EyeOfGod — Приложение для поиска и анализа информации, включая поиск по изображениям и проверку источников. eyeofgod.app
